Slug URL dibuat otomatis dari nama (misalnya "Rak Sepatu" → "rak-sepatu"). Kategori baru memakai ikon generik.

Tambah Produk Baru

Foto otomatis dikonversi ke JPG dan disimpan ke asset/images/products/<slug>/, dan data produk otomatis ditulis ke asset/js/products.js, saat produk disimpan (butuh folder project terhubung — tombol di kanan atas). Setelah itu tinggal git add . && git commit && git push. Tanpa folder terhubung, unggah manual file 1.jpg, dst ke folder tersebut dan edit products.js manual.

Masih melihat saran nama/ukuran lama saat mengetik? Itu riwayat autofill browser (bukan data produk). Arahkan mouse ke saran yang mau dibuang lalu tekan Shift+Delete (Chrome/Edge/Firefox) untuk menghapusnya satu per satu. Field ini sudah diatur agar tidak menyimpan saran baru lagi.
